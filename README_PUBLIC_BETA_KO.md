# Smart Clock 공개 베타 준비물

## 현재 공개 주소
- https://alarm-lemon-omega.vercel.app
- 발표/배포용 QR은 위 주소를 QR 코드로 변환해 사용하면 됩니다.

## 이번 작업에 포함된 변경
- `api/push-unsubscribe.js`: 현재 브라우저의 푸시 구독 및 서버에 저장된 해당 브라우저의 알람 레코드 삭제 API
- `index.html`: 푸시 알림 버튼을 다시 누르면 이 기기의 푸시 알림 해제/서버 레코드 삭제를 선택할 수 있도록 변경
- `privacy.html`: 데이터 처리 안내 페이지
- `terms.html`: 공개 베타 이용 안내 페이지

## 앱을 닫은 상태의 PWA 알림 개선
- 반복 알람은 서버의 예약 시각을 시간대 기준 UTC로 계산하도록 수정했습니다.
- Google Apps Script의 분 단위 확인 작업이 예약 분보다 늦게 실행되어도 10분 이내면 알람을 놓치지 않고 푸시를 보냅니다.
- 푸시 서비스가 기기를 잠시 오프라인으로 판단한 경우를 위해 푸시 TTL을 10분으로 늘렸습니다.
- 서비스 워커 캐시 버전을 `smart-clock-v8`로 올렸습니다.

### 반드시 필요한 서버 설정
1. Vercel 환경 변수에 `CRON_SECRET`, `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`을 등록합니다.
2. Google Apps Script의 `google-apps-script/Code.gs`에서 배포 URL과 동일한 `CRON_SECRET`을 설정합니다.
3. Apps Script에서 `configureSmartClock()`을 1회 실행하고, `installMinuteTrigger()`를 1회 실행합니다.
4. 앱에서 각 기기별로 푸시 알림을 켜고, 알람을 저장한 뒤 앱을 닫아 실제 수신을 시험합니다.
5. 아이폰은 Safari에서 사이트를 홈 화면에 추가하고, 홈 화면 아이콘으로 실행한 뒤 푸시를 허용해야 합니다.

### 알림 동작 범위
앱이 닫혀 있어도 서버가 푸시 알림을 발송하고 운영체제가 알림을 표시하도록 하는 PWA 방식입니다. 알림의 소리와 진동은 기기의 알림 설정을 따릅니다. 기존 12개 앱 내 알람 음원을 앱이 닫힌 상태에서 계속 재생하는 기능은 웹 푸시 API가 제공하지 않으므로, 해당 동작은 네이티브 알람 기능에서 구현해야 합니다.

## GitHub 반영
1. 기존 저장소에 업데이트된 `index.html`을 덮어씁니다.
2. `api/push-unsubscribe.js`를 `api` 폴더에 추가합니다.
3. `privacy.html`, `terms.html`, `README_PUBLIC_BETA_KO.md`를 프로젝트 루트에 추가합니다.
4. GitHub에 커밋합니다. Vercel의 최신 배포가 `Ready`인지 확인합니다.
5. 다음 주소가 열리는지 확인합니다.
   - `/privacy.html`
   - `/terms.html`
   - `/api/health`

## 공개 베타 전 필수 확인
- [ ] 개인정보 안내의 `[운영자 이메일 주소 입력 필요]`를 실제 문의 주소로 교체
- [ ] 개인정보 안내가 실제 운영/보관 방식과 일치하는지 확인
- [ ] 서로 다른 기기/브라우저 두 개에서 각각 알람을 만들어 데이터가 섞이지 않는지 테스트
- [ ] 푸시 허용, 푸시 수신, 푸시 해제, 재구독 테스트
- [ ] 사용자에게 웹 푸시와 네이티브 알람의 차이를 안내
- [ ] Android APK 및 iOS 앱은 별도 네이티브 빌드/실기기 검증 후 배포

## 중요한 현재 제한
- 현재 웹 버전은 계정 기반 동기화가 아닙니다. 각 브라우저의 로컬 알람은 해당 브라우저에 저장됩니다. 푸시 구독을 켠 브라우저는 그 구독에 연결된 알람을 서버에 저장합니다.
- 다른 기기 사이의 알람 목록 자동 동기화/사용자 계정은 아직 구현되어 있지 않습니다.
- iOS/Android 네이티브 소스는 실제 기기 빌드 및 테스트가 별도로 필요합니다.
- 공개 베타 단계에서 중요한 알람의 유일한 수단으로 사용하지 않도록 안내하세요.

## 개인정보 관련 동작
푸시 해제는 현재 브라우저의 구독을 서버에서 삭제한 다음 브라우저 구독 해제를 시도합니다. 기기의 로컬 알람 데이터는 삭제하지 않습니다. 브라우저 사이트 데이터 삭제만으로 서버 레코드가 삭제된다고 안내하지 마세요.
