# 스마트 시계 Android 네이티브 알람 안내

기존 프로젝트의 `android-native` 폴더에 Android Studio용 앱 소스가 추가되었습니다.

웹 프로젝트 `index.html`도 Android 앱과 알람 정보를 동기화하도록 수정되었습니다. **GitHub에 수정된 index.html을 반영하고 Vercel 재배포를 마친 뒤** Android APK를 빌드하세요.

자세한 설치·권한·테스트 방법은 `android-native/README_ANDROID_KO.md`를 읽어 주세요.

주의: 이 ZIP은 Android 소스 프로젝트이며, Android SDK가 없는 생성 환경에서 APK를 빌드하거나 실제 기기에서 검증한 것은 아닙니다.
