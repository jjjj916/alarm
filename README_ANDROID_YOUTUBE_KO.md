# 안드로이드에서 유튜브 앱 시청 중 Smart Clock 알림 안내

## 적용 내용
- Android 기기에서만 유튜브 앱 시청 중 알림 설정 안내를 표시합니다.
- 푸시 구독 완료 메시지에서 OS 알림과 Smart Clock 사용자 지정 알람음을 구분합니다.
- 서비스 워커 캐시를 v11로 갱신합니다.

## 휴대폰 설정
1. 설정 → 앱 → Chrome(또는 Smart Clock을 실행한 브라우저) → 알림 허용
2. Chrome의 알림 카테고리/사이트 알림에서 소리와 진동 허용
3. 설정 → 앱 → Chrome → 배터리에서 백그라운드 사용 제한 해제 또는 제한 최소화
4. 데이터 절약 모드 사용 시 Chrome 백그라운드 데이터 허용
5. 방해 금지 및 무음 모드 확인

메뉴 명칭은 Android 버전과 제조사에 따라 다릅니다.

## 중요한 기술적 한계
유튜브 앱으로 전환하면 PWA 페이지의 JavaScript와 Web Audio가 백그라운드에서 중단될 수 있습니다. 이때 서비스 워커의 푸시는 OS 알림을 표시할 수 있지만, 알림 소리는 Android/Chrome 알림 채널 설정을 따릅니다. 웹 푸시로 Smart Clock의 12개 사용자 지정 음원을 임의로 재생할 수 없습니다. 현재 서버 점검은 분 단위이므로 정각 전달도 보장하지 않습니다.

기상 등 중요한 용도의 단독 알람으로 사용하기 전에 실제 휴대폰에서 충분히 시험하고, 휴대폰 기본 알람을 함께 설정하세요.
